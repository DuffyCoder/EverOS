# Historical Evaluation Records

This directory preserves historical plans, design specifications, runbooks, and
phase records created during earlier evaluation work. The paths remain stable so
commits and retrospective analysis can continue to reference them.

These records describe decisions and repository states at the time they were
written. They may mention obsolete commands, paths, images, assumptions, or
unfinished work and are not the current repository contract.

- `plans/` contains historical implementation plans.
- `specs/` contains historical designs, findings, and phase records.
- `runbooks/` contains operator procedures from those phases; validate every
  command against current code before use.

For current ownership and reproducibility policy, see
[`docs/evaluation/`](../evaluation/README.md). For framework commands and
component operations, see [`evaluation/README.md`](../../evaluation/README.md)
and [`evaluation/docs/`](../../evaluation/docs/README.md).
